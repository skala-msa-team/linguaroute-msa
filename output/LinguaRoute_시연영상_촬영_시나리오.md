# LinguaRoute 발표 시연영상 촬영 시나리오

> 예상 시간: 4분 30초~5분
> 핵심 흐름: 기업 구독·좌석 → 직원 강의 탐색·AI 추천·학습 → 플랫폼 운영
> 원칙: 조회·필터만 사용하고 결제, 초대, 수강 상태, 강의 상태는 변경하지 않습니다.

## 1. 촬영 전 준비

- Chrome 확대율을 100%로 맞추고 주소창이 보이도록 합니다.
- 프론트엔드 `http://localhost:3000`과 Docker Compose 서비스 상태를 확인합니다.
- 로그인 계정은 `README.md`의 데모 계정을 사용합니다.
- 화면의 진도율과 운영 집계는 촬영 시점의 서버 응답값을 그대로 읽습니다.
- AI 추천 요청은 이력을 저장하므로 영상 중 한 번만 실행합니다.

## 2. 시연 순서와 발표 대본

### 0단계. 랜딩 화면 — 20초

**Chrome 조작**

1. `http://localhost:3000` 접속
2. LinguaRoute 로고와 메인 문구 확인
3. ‘직원’, ‘관리자’, ‘플랫폼’ 소개 영역까지 천천히 내림

**발표 대본**

> “LinguaRoute는 기업이 구독하고 소속 직원이 학습하며, 플랫폼 관리자가 전체 상태를 운영하는 B2B 외국어교육 구독 플랫폼입니다. 지금부터 기업 관리자, 직원, 플랫폼 관리자 순서로 실제 API 연동 흐름을 보여드리겠습니다.”

### 1단계. 기업 관리자 — 1분 10초

**Chrome 조작**

1. `로그인` 선택 → `회사 계정으로 로그인`
2. 기업 관리자 데모 계정으로 로그인
3. `기업 학습 현황` 대시보드의 활성 직원, 잔여 좌석, 수강 중 강의, 평균 진도율 확인
4. `요금제 · 결제` 이동 → `ACTIVE` 구독과 결제 `SUCCESS` 확인
5. `직원 · 초대` 이동 → 구매·사용·잔여 좌석과 직원 목록 확인
6. `학습 현황` 이동 → 직원별 수강 상태와 진도율 확인

**발표 대본**

> “먼저 기업 관리자 화면입니다. 대시보드는 소속 직원과 좌석, 수강 상태를 실제 API로 조회합니다. 구독·결제 화면에서는 현재 구독이 ACTIVE이고 결제가 SUCCESS인 것을 확인할 수 있습니다. 결제 결과는 Kafka 이벤트를 통해 좌석과 수강 권한에 반영됩니다. 마지막으로 학습 현황에서 직원별 수강 건수와 서버가 계산한 진도율을 확인합니다.”

### 2단계. 직원 강의 탐색·AI 추천·학습 — 2분

**Chrome 조작**

1. 화면의 `로그아웃` → 확인 다이얼로그의 `로그아웃`
2. 직원 데모 계정으로 로그인
3. `강의 찾기` 이동
4. 전체 `ACTIVE` 강의 목록 확인
5. 언어를 `일본어`로 변경
6. 요청 후 `일본 출장 회화`, `JAPANESE`, `ACTIVE` 조건을 설명
7. `AI 강의 추천` 이동
8. `영어` → `고급` → `다음`
9. 직무 `글로벌 세일즈`, 상황 `업무 발표` → `다음`
10. 준비된 학습 목표를 확인하고 `AI 추천 결과 보기` 한 번 선택
11. 추천 강의의 제목, 추천 이유, `AI 추천` 출처 안내 확인
12. `내 학습` 이동 → `COMPLETED` 강의와 `LEARNING` 강의, 현재 서버 진도율 확인

**발표 대본**

> “다음은 직원의 학습 흐름입니다. LinguaRoute의 차별점은 일반 회화 추천이 아니라 해외 고객 미팅, 업무 발표처럼 실제 직무의 비즈니스 시나리오와 전문용어 학습 목표를 강의 선택에 반영하는 것입니다. 직원이 언어, 수준, 직무, 상황과 자연어 목표를 입력하면 AI가 후보를 고르고, 서버는 실제 ACTIVE 강의인지, 요청 언어와 일치하는지, 이미 수강 중인 강의인지를 다시 검증합니다. 내 학습 화면에서는 완료된 강의와 학습 중인 강의의 현재 진도율을 확인할 수 있습니다.”

### 3단계. 플랫폼 관리자 — 1분

**Chrome 조작**

1. `로그아웃` 후 플랫폼 관리자 데모 계정으로 로그인
2. `운영 대시보드`의 전체 기업·사용자·결제·수강 집계 확인
3. `강의 관리` 이동
4. 상태를 `INACTIVE`로 선택하고 `필터` 선택
5. 비활성 강의와 `활성화` 버튼만 확인하고 누르지 않음

**발표 대본**

> “마지막은 플랫폼 관리자 화면입니다. 운영 대시보드는 기업, 사용자, 결제, 수강 상태를 각 도메인 API에서 조회해 표시합니다. 강의 관리에서 INACTIVE 필터를 선택하면 일반 직원에게는 노출되지 않는 비활성 강의까지 운영할 수 있습니다. 시연에서는 데이터 보존을 위해 활성화 버튼을 누르지 않습니다.”

### 4단계. 마무리 — 20초

**발표 대본**

> “지금까지 기업의 구독과 좌석, 직원의 강의 탐색과 AI 추천, 학습 진도, 그리고 플랫폼 운영까지가 하나의 경로로 연결되는 것을 확인했습니다. LinguaRoute는 AI가 추천 후보를 판단하고, 각 도메인 서비스가 권한과 실제 데이터를 검증하는 구조로 구현했습니다. 감사합니다.”

## 3. 촬영 중 누르지 않는 버튼

- `구독 해지`, `결제 정보 입력`
- `초대코드 생성`, `비활성화`, `소속 해제`
- `수강 신청`, `학습 시작`, `차시 완료`
- `강의 저장`, `활성화`, `비활성화`
- `비밀번호 변경`, `회원 탈퇴`

## 4. 실패 시 복구 멘트

- 화면이 느리면: “현재 API Gateway 뒤의 도메인 서비스 응답을 기다리고 있습니다.”
- 로그인이 풀리면: “Access Token이 만료되면 재로그인하는 MVP 정책을 사용합니다.”
- 추천이 느리면: “AI 응답 후에도 서버가 실제 ACTIVE 강의인지 다시 검증합니다.”
- 화면 숫자가 준비 자료와 다르면: “현재 화면은 서버의 실제 응답값을 반영하고 있습니다.”
