# LinguaRoute MVP 체크리스트

> 문서 상태: 구현 진행 관리

## 체크 규칙

- `[ ]`는 미완료, `[x]`는 완료를 의미합니다.
- 강사 제공 코드에 비슷한 기능이 있어도 실제 요구사항과 일치하는지 검증하기 전에는 완료 처리하지 않습니다.
- 코드 구현, 관련 테스트, API 또는 화면 실행 확인, 관련 문서 갱신까지 끝난 기능만 `[x]`로 변경합니다.
- 완료 체크는 해당 기능을 구현한 Pull Request에서 코드 및 문서와 함께 반영합니다.
- 선택·보류·추후 확장 기능은 확정 MVP 진행률에 포함하지 않습니다.
